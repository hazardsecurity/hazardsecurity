### 🛠 What I'm building

- **[HazardSign AI](https://hazardsign-ai.vercel.app)**: sign documents of any type online. Files are signed and sealed in the browser and never leave the device; every signed copy carries an audit certificate with its SHA-256 fingerprint.
- **More small projects on the way**, each one shipped as its own product.

### ⚡ How I like to build

- Ship something real, then refine it
- Security by default: hashed secrets, signed webhooks, least access
- Interfaces with considered typography and motion, not templates
